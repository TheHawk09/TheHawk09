### Featured Project

#### [DiamTek JVM (Java Version Manager for Windows)](https://github.com/DiamTek/Java-Version-Manager-Windows)

A native, dependency-free Java Version Manager designed specifically for Windows environments. Solves multi-JDK version switching, PATH corruption, and registry misconfigurations without requiring heavy background runtimes or third-party package managers.

- **Architecture:** Pure Windows Batch script core engineered for instant execution, zero installation overhead, and native shell portability.
- **Reliability:** Automates dynamic `JAVA_HOME` and user/system `PATH` updates while maintaining environment variable integrity.
- **Stack:** `Batch Scripting` • `Windows CLI` • `JDK Environment Lifecycle`

[![View Repository](https://img.shields.io/badge/View_Repository-DiamTek%2FJava--Version--Manager--Windows-0052CC?style=flat&logo=github)](https://github.com/DiamTek/Java-Version-Manager-Windows "DiamTek JVM (Unshittifying the shittiness of Windows PATH management)")
